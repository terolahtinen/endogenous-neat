Tests run for paper. Output is under final_runs/.

--mode compare now launches all five arms, including random-theta.
The two random-theta lines below are the separate launches used before that change.
Repeating them into the same directory would add a second random-theta batch.

# 19-character target, 250 generations.
# Paper uses 20261010_193132 (50 x standard, standard-random, inherited-theta, meta-theta)
# and 20261013_175303 (50 x random-theta).
python -m endogenous_neat.experiment --task guess-word --mode compare --generations 250 --runs 50 --output-dir final_runs/guess_word --seed-fill elite --seed 0 --answer 'michael soumen ingo'
python -m endogenous_neat.experiment --task guess-word --mode random-theta --generations 250 --runs 50 --output-dir final_runs/guess_word --seed-fill elite --seed 0 --answer 'michael soumen ingo'
